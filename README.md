## 📖 系统概述

**Retro Taxi Meter Pro** 是一款高度拟真、基于地理信息系统（GIS）及 Web Audio 合成技术的高性能单页计量与收银 Web 应用。

本系统秉持“降本增效、物理直观、极度合规”的设计理念，完美复刻了 90 年代经典车载计价器的物理反馈，并集成了现代收银 POS 机小费结算组件。系统内置极佳的离线支持（PWA）和防止逃废债机制，是一套面向全行业运输服务驾驶员的零延迟、闭环式收银解决方案。

## 🛰️ 核心技术架构与特性

### 1. 高精度里程与蠕行复合计费引擎 (GIS & Speed Filters)
*   **Haversine GIS 滤波测距**：基于高阶大地经纬度公式计算行驶弧长，通过双重卡尔曼式位置滤波消除 GPS 的随机信号漂移。
*   **蠕行静止判定 (Dual-Filter Speed Threshold)**：智能监测瞬时速度与单位位移（以 3 米为防抖窗口）。当红绿灯等待或严重堵车时，系统能精准过滤空间漂移产生的“幽灵里程”，保障计量合规与行业声誉。
*   **智能昼夜自适应**：系统上电时自动读取实际系统时钟。当时间处于 `23:00 - 次日 05:00` 运营核心区间时，物理 LED 会点亮“NIGHT 夜间”红色指示灯，自动对基础价格和公里单价加收 **1.3 倍的夜间服务附加费**。

### 2. 拟物化 LED 仿真与音频反馈组件 (Web Audio Synth)
*   **物理微动声音合成**：完全丢弃庞大的第三方音频库，采用 Web Audio API 实时代码合成高音滑落的“咔哒 (Click)”微动开关音调，以及温和低沉的“啪嗒 (Clack)”塑料机械空车牌翻转音效。
*   **iPhone 刘海屏物理避让**：通过 CSS `env(safe-area-inset-top)` 计算，在 iPhone 灵动岛或物理刘海下实现高保真安全边距，确保运行状态字样绝不遮挡。

### 3. 🛡️ 极值财务冗余与字号自适应防护 (Big Number Overflow Defense)
*   **999,999.00 元财务封顶**：为防范司机在极端溢价或超长途行驶下车资超出物理屏幕承受边界，系统预设了极值防护，将订单总额强制拦截在 **`999999.00`** 元。
*   **LED 字号无损缩放 (Auto Scale)**：
    *   金额字符超出 6 位（百元级）时，屏幕自动注入 `.long-value` 样式，字号缩至 `11.5vw`。
    *   金额字符超出 8 位（十万及百万级）时，自动注入 `.super-long-value` 样式，字号收缩至 `9.2vw`。
    *   这确保了极端大数财务结算下，LED 字符自适应拉伸显示，界面绝无溢出或折行崩裂的灾难性后果。

### 4. ↩️ 全流程保姆级双向回退纠偏流转 (Dual-Way Flow Loop)
*   **无忧操作安全机制**：本终端在「基础车资计量」→「附加费及路桥费录入」→「比例小费追加」→「扫码收银台」四个流转层级间提供了完美的**双向返回与纠偏机制**。
*   **寄存器寄存记忆**：当从小费页面选择“修改附加费”退回到上一步时，系统寄存器会完整保留司机之前填写的附加费与路桥费，避免重复输入，将驾驶员人工录入失误的纠偏成本降至最低。

### 5. ⚡ 「打车借呗·一键渡劫贷™」级联小额网贷清算平台 (Micro-Loan Integrated Portal)
为解决高额车资支付时常伴随的“流动性不足”及“乘客面临财务破产”等痛点，系统搭载了业界首创的紧急金融清算保障组件：
*   **紧急VIP融资通道**：当订单金额触及 `999,999.00` 元硬性上限时，主终端的「支付」按钮将立即变异为**「⚡ 余额不足，一键渡劫」**并伴随高频金色警报呼吸闪烁。点击即可一键跳转至「破产清算彩蛋页面」。
*   **金融级闪电授信额度**：面向破产边缘用户，系统提供最高 `1,000,000` 元授信额度。凭借 250% 限时特惠年化利率，配以前 5 秒免息的科学利率模型，一秒到账并自动扣划付清司机账单。
*   **债务人合同锁定与防逃废债机制**：
    *   借贷审批通过后，后台自动执行强制划转划扣。最终账单界面瞬间更新为 `🎉 账单已结清 (网贷代扣)`，并在此页加盖高对比度 **`PAID 已结清`** 物理倾斜防伪印记，强行隐藏扫码区域以保护司机收款账户隐私。
    *   **为维护债权债务契约的即时成立，一旦扣款成功，系统将永久锁定当前账单！** 强行封锁并隐藏所有“返回修改”回退按钮，仅保留 100% 撑满物理屏幕的「再来一单」清空重开选项，确保资金回回一锤定音。

## 🔄 3. 重开与物理清理算法 (Garbage Collection)

当车辆结算完毕，点击「再来一单」或债务人「放弃借款去工地搬砖」时，系统会执行高规格的物理内存清理：
1.  **传感器零漂清除**：强制清空 GPS 累计轨迹缓存（`state.lastPos = null`，`state.lastTimestamp = 0`），消除传感器残留的末端尾数，避免新行程出发时产生瞬间信号跃变和计算漂移。
2.  **变异控制状态清空**：剥离全部金色警报 Class，将主屏的 `.btn-next` 物理按钮完美打回原形（恢复“支付”默认文案与正常流程）。
3.  **LED 硬件复位**：车资强制清空为 `0.00` 并刷新数码管，自动清空大数爆屏样式，恢复原本饱满有张力的超大 LED 字体。

## ⚙️ 系统部署与安装说明

### 1. 环境依赖
*   本系统为 **100% 静态纯前端单页 App (SPA)**。
*   零服务器开销，无任何外部库（如 Tailwind、React 等）依赖。
*   物理交互安全及 GPS 定位数据强制要求运行在 **HTTPS 环境**（或 localhost 调试环境）。

### 2. 本地快速体验
只需将项目克隆到本地目录，在任何 Web 容器（如 HTTP-Server, Live Server）中挂载即可运行：
```bash
# 建议在包含 https 签名的沙盒环境或移动端 Web 容器中打开 index.html
open index.html
```

### 3. PWA 离线运行模式 (PWA Support)
本应用符合 PWA 标准规范。首次通过浏览器加载后，应用会自动通过后台 `service-worker.js` 对图标 `icon.svg`、样式 `style.css`、交互 `script.js` 进行离线缓存。在后续断网、野外长途等无网络信号环境下，本计价器依然可以 **100% 离线完美运转**。
