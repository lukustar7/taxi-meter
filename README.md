# Retro Taxi Meter Pro v1.4.2

复古出租车计价器模拟网页，使用 GPS 位移估算里程，并提供附加费、小费、收款码和 PWA 离线运行能力。

在线地址：https://lukustar7.github.io/taxi-meter/

## 功能

- 原生 HTML、CSS、JavaScript 实现，无第三方运行依赖。
- 支持起步价、起步里程、续租费、返空里程和返空倍率配置。
- 支持 23:00 至次日 05:00 夜间倍率提示与重新核算。
- 支持 PNG、JPG、WebP 收款码上传，图片会压缩后仅存储在本机浏览器。
- 支持 PWA 安装、核心静态资源离线缓存和手机主屏图标。

## 技术结构

- `src/domain.js` 存放运价、账单、时间和 GPS 样本规则，不依赖页面环境。
- `src/device.js` 隔离音效、振动和屏幕常亮等浏览器设备能力。
- `src/app.js` 统一管理页面状态、事件绑定、设置存储和结算流转。

## 使用

1. 打开网页后允许浏览器定位权限。
2. 在设置中确认费率和收款码。
3. 点击“开始”记录行程，点击“结束”进入结算流程。

## 限制

- 本项目仅用于学习、演示和娱乐，不得用于真实道路客运、网约车或出租车营运。
- 当前计费模型以 GPS 里程为主，不包含真实出租车的等待费、低速费、平台服务费和地区完整法规规则。
- GPS 在隧道、高楼密集区、弱网或省电模式下可能出现漂移、延迟或漏记。

## 本地运行

```bash
python3 -m http.server
```

浏览器访问 `http://localhost:8000/`。

## 本地验证

```bash
npm run build
```

该命令执行 JavaScript 语法检查和零依赖自动化测试。
