## 📖 这玩意儿是干嘛的？

这是一个专为极客把玩、整蛊朋友开发的复古出租车计费模拟工具。

它用原生前端代码（不依赖任何第三方库）高度拟真地还原了 90 年代老式计价器的物理按键声、机械翻牌效果以及昼夜自适应液晶屏（23点到凌晨5点自动进入夜间加成模式）。

## 😈 怎么用它整蛊你的朋友？

为了达到最震撼的节目效果，建议通过以下步骤在副驾驶进行“加速路测”：

1. **设置天价费率**：点击右上角 **⚙️ 设置**，将起步价或续租费填成一个夸张的数字（比如一公里 10 万元）。
2. **开启发车仪式**：点击 **「开始」**，伴随清脆的“啪嗒”翻牌声，空车牌倒下，计费启动。
3. **见证大数封顶**：车辆稍微位移，车资便会瞬间跳动飙升。当车费触及极限值 **`999,999.00`** 元时，系统会自动硬性截断封顶，且 LED 屏字号会自动缩小防爆屏，保证百万巨款完美呈现。
4. **一键渡劫贷**：司机点击 **「结束行程」**，原本的支付按钮会变红并金色闪烁。点击后直接强行跳转到山寨感十足的 **「打车借呗·一键渡劫贷™」** 借贷卡片页面（限时特惠年化 250%，前 5 秒免息）。
5. **代扣已结清**：乘客被迫点击“立即借款付清”后，系统会自动代扣完毕，生成盖有倾斜 **PAID** 防伪安全印章的电子结清收据，并锁定退改通道防逃废债，直到司机点击「再来一单」彻底复位清零。
